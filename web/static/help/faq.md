# 常见问题

本章按功能列出使用中最常遇到的现象、可能原因和处理办法。排障时先看页面上的错误提示，提示里通常已经写明具体原因（缺哪张表的权限、哪条规则拦截、哪一级无人审批）；仍无法定位时，带上提示原文联系管理员或所在资源组的负责人。

## 权限与菜单

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 看不到某个菜单或按钮 | 没有对应权限；按钮悬停提示里写着需要的权限码 | 到「访问控制 › 权限组 › 按用户查看有效权限」确认这个码的来源或为什么缺失；查询类场景到[权限申请](#help/qpriv)申请库表权限；其余联系管理员或所在资源组负责人授权 |
| 按钮显示“仅超级用户可用” | 该码是锁定码，权限组授不出去 | 只能由超级用户操作，见 [按钮级权限](#help/btnperm) |
| 只能看到部分实例 | 实例按资源组关联，你所在资源组没关联的实例不会出现；停用的实例也不出现 | 联系管理员把实例加入你的资源组 |
| 刚被授权但页面没变化 | 权限缓存最长约 15 秒 | 稍等并刷新页面 |
| 提交工单时实例下拉里没有目标实例 | 实例没有带“可以写入”（`can_write`）标签、不在所选资源组内，或类型不支持工单 | 联系 DBA 检查实例标签与资源组关联 |

## SQL 上线

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 工单提交后没有人审批 / 卡住了 | 审批流的某一级没有人有审批权限；你自己是那一级唯一的审批人（不能自己审批自己）；审批人不在工单所属的资源组里 | 管理员在「审批流程」里查看“无人可审”警告并补人，见 [管理员指南](#help/sysadmin) |
| SQL 检查提示“基础检查 / 降级” | goInception 没配置或不可用，只做词法级检查，没有影响行数和备份 | 联系管理员配置，详见 [管理员指南](#help/sysadmin) |
| 提示“DDL 语句和 DML 语句不能同时执行” | 管理员开启了 DDL / DML 分离（`review.ddl_dml_separation`，默认关闭）；注意 `DELETE` 也归为 DDL 类 | 把 DDL 和 DML 拆成两张工单 |
| 提示“您提交的是 DDL 语句，请选择 DDL 资源组” | 资源组名称里带 DDL / DML 字样时，语句类型必须与资源组一致 | 换成对应类型的资源组 |
| 提示“仅支持DML和DDL语句，查询语句请使用SQL查询功能” | 工单里不能提交 `SELECT` | 查询改走[在线查询](#help/query)，要导出走[数据导出](#help/export) |
| 执行有异常，要怎么办 | 执行是“失败即停”：已成功的语句已生效，后面的标“未执行” | 到目标库确认现状；开启了备份的可以[查看回滚语句](#help/sqlworkflow)；修复语句另开新工单 |
| 为什么不能终止“执行中”的工单 | SQL 已发往目标库，无法安全撤回 | 大表改动请使用在线改表（OSC）并通过暂停 / 终止控制；执行时间太长时由 DBA 使用「取消执行」 |
| 工单一直停在排队中 / 执行中 | 服务被重启或强杀导致执行进程失联 | 系统会在几分钟内自动置为“执行有异常”；也可在详情页“执行进程失联了？”里手工标记，之后务必到目标库核对 |
| 提示未开启“上线”权限（缺少 `can_write` 标签） | 目标实例没有“可以写入”标签 | 联系 DBA 在实例列表里给实例打标签 |

## 查询与导出

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 查询提示没有权限 | 对语句涉及的库表没有有效的查询权限，或权限已过期 | 到[权限申请](#help/qpriv)申请库表权限，审批通过后即时生效 |
| 已经有表权限，非 MySQL 类型实例仍提示无权限 | 表级校验只对类型为 MySQL 的实例精确到表；PolarDB、PolarDB-X、SelectDB、Doris、ADB、SQL Server 按库校验 | 申请这些实例的**库权限**，见 [权限申请与查询权限](#help/qpriv) |
| 查询结果被截断 | 触发了行数上限，上限取你在这些表上权限里的最小限制 | 需要更多数据请走[数据导出](#help/export)（默认单次 ≤ 1 万行） |
| 导出下载不了 | 缺少下载权限（`export.download`），或文件已过保留期，或工单还没执行完 | 联系管理员授权；文件被清理后重新提交导出工单 |
| 在线查询里为什么不让我 `SELECT *` | 管理员开启了禁用通配符（`query.forbid_select_star`） | 从左侧对象树点表名可以自动展开字段 |
| 运行前弹窗要求填写原因 | 语句命中 SQL 防火墙“要求填写原因”规则 | 填写 4 到 200 字的原因后继续，见 [SQL 防火墙](#help/firewall) |
| 语句被“防火墙”拦截 | 命中了拒绝类规则；被拦截的语句不会连接目标库 | 按提示调整语句，或联系管理员评估规则，见 [SQL 防火墙](#help/firewall) |
| 结果里的手机号等显示成带星号的值 | 命中了数据脱敏规则，管理员同样会被脱敏 | 属正常行为，规则见 [数据脱敏](#help/masking) |
| 明明不是敏感字段的列也显示成脱敏结果 | 保守匹配宁多勿漏：列的表达式引用了敏感字段名，调用了存储函数 / 自定义函数，取自被污染的别名、变量或表变量，或别的库表里的同名字段配置过 | 属正常行为，判断规则见 [数据脱敏](#help/masking) 的“保守匹配” |
| SQL Server 提示“INSERT 只能写入 DECLARE @变量 TABLE (…) 声明的表变量” | 在线查询和导出是只读的，批处理里只允许往 `DECLARE @t TABLE (…)` 声明的表变量里 `INSERT`，不能写表、`#临时表`或没声明的变量 | 把中间结果放进表变量，最后用 `SELECT` 输出；要写真实表请走 [SQL 上线](#help/sqlworkflow)，规则见 [在线查询](#help/query) |
| 导出（或“检查并统计行数”）提示“连接数据库实例超时”“网络连接超时”“无法连接数据库实例”“连接被中断” | 实例不可达、查询太慢（没走索引、数据量大），或网络 / 防火墙中断了长连接；提示末尾的“原始错误”带着地址和端口 | 按提示确认地址、端口和网络；读取超时就缩小范围、加过滤条件或避开业务高峰后重试（批量导出点失败实例的重试），仍然超时联系 DBA 检查网络，见 [数据导出](#help/export) |

## 登录与账号

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 登录时被要求输入验证码 | 已开启两步验证 | 输入验证器（TOTP）或短信验证码；换手机后验证器丢失，联系管理员“重置 2FA”后重新绑定 |
| 账号被锁定 | 连续输错密码达到阈值（默认 5 次，锁定 300 秒） | 等待锁定时间过后重试，或请管理员在用户页里“解锁”，详见[登录章节](#help/login) |
| SSO 登录后提示账号不存在 | 登录方式被设为“仅限已有用户”，且按配置的匹配依据没有找到平台用户 | 联系管理员建号，或检查邮箱 / 用户名是否一致 |
| 改密码页提示没有本地密码 | LDAP / SSO 账号的密码在各自系统里维护 | 到公司统一身份平台修改 |
| 页面时间差 8 小时 | 服务时区与数据库 / 浏览器不一致 | 反馈给管理员（时区配置不一致） |

## 性能工单

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 工单为什么突然被重开了 | 同一条 SQL 在关闭后再次变慢且影响超过阈值，系统会自动重开 | 确属误报请 DBA 使用“误报关闭”，之后不再重开 |
| 延期按钮是灰的 | 已达该级别的最大延期次数（P0 不允许延期），或已有待审批的延期 / 豁免申请，或工单不在计时状态 | 联系 DBA |
| SLA 为什么没在计时 | 只有待分派、待受理、处理中三种状态计时；待验证和豁免审批中会暂停 | 属正常行为，见 [性能工单](#help/perf) |

## 数据归档

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 归档任务提交不了，提示没有审批流 | 所选资源组没有配置“数据归档申请”的审批流（或审批流里没有任何有审批权限的权限组） | 请管理员在「审批流程」里为该资源组配置，详见 [数据归档](#help/archive) |
| 立即执行被拒绝 | 源表有未结束的 SQL 上线工单、同实例的归档运行已达并发上限、备份存储当前不可用、当前不在执行窗口内 | 提示里会写明具体原因；窗口外可勾选“忽略执行窗口”（负载保护仍然生效） |
| 任务被自动暂停了 | 连续多批失败、校验失败或源表结构变化 | 原因写在任务详情里；处理完再“恢复任务”；结构变更暂停需要重新试运行并重新提交审批 |
