# 登录、两步验证与账号安全

本章说明如何登录 dbtool、两步验证怎么用、忘记密码和账号被锁定怎么办，并给管理员说明登录方式（LDAP / OIDC / 钉钉 / CAS / 飞书 / Lark / Slack / 企业微信）与“安全策略”的配置方法。普通用户读“适用范围”到“账号绑定”各节即可，管理员再读“登录认证”“安全策略”。

## 适用范围

登录页按管理员配置显示以下入口，可以并存：

| 方式 | 说明 |
|---|---|
| 本地账号密码 | 平台自己的账号（密码哈希为 pbkdf2_sha256） |
| LDAP | 在同一个账号密码表单里输入公司目录账号；平台不保存 LDAP 密码，忘记密码请到公司统一身份平台找回 |
| 单点登录（SSO） | 页面上的“使用 xxx 登录”按钮：飞书 / Lark、钉钉、企业微信、OIDC（公司 SSO）、CAS、Slack。点击后跳转到对应授权页，授权后回到平台 |

两步验证方式只有两种：TOTP 动态口令（验证器 App）和短信验证码，**没有备用码**。

## 前提条件与所需权限

| 事项 | 要求 |
|---|---|
| 登录 | 有启用的平台账号，或管理员允许你的外部身份登录（见“外部账号如何对应到平台用户”） |
| 修改密码 | 仅本地账号；新密码要满足密码策略 |
| 绑定外部账号 | 管理员在“通用规则”里开放了“允许用户自行绑定 / 解绑外部账号” |
| 登录认证 | 仅超级用户；权限码 `authp.view` / `authp.test` / `authp.edit` / `authp.toggle` 都是锁定码，不能授予权限组 |
| 安全策略 | 仅超级用户；权限码 `sec.view` / `sec.edit`，同为锁定码 |

## 登录页

登录页的卡片里只有用户名、密码、“记住账号”和登录按钮；管理员配置了单点登录时，卡片上方会出现对应的登录按钮（如“使用公司账号登录”），平台账号表单可能折叠在“或使用平台账号”下面，点开即可输入。

- **没有账号**：请联系资源组负责人或 DBA 开通；管理员开放了自助注册时，卡片底部有“没有账号？注册用户”。
- **记住账号**：只把用户名记在本机浏览器里，不保存密码；取消勾选后下次登录不再预填。
- **显示 / 隐藏密码**：密码框右侧的“显示”按钮。
- **忘记密码**：点“忘记密码？”按账号类型查看找回方式，见下面“忘记密码”。
- **登录安全**：连续输错密码会临时锁定账号（见“账号锁定”）；登录、登录失败、账号锁定等所有操作都记录审计。

登录页的“本地账号密码表单”可被管理员设为始终显示 / 折叠 / 隐藏（默认折叠）。**超级用户永远可以用 `/login?local=1` 走本地账号**——即使 SSO 故障或表单被隐藏，管理员也不会被锁在门外；超级用户默认只允许本地登录（不走 LDAP / SSO）。

### 忘记密码

| 账号类型 | 怎么办 |
|---|---|
| LDAP / AD 域账号 | 到公司统一身份平台找回密码；平台不保存也无法重置域密码 |
| 本地账号 | 联系管理员在“访问控制 › 用户”里重置密码；管理员可以“系统生成临时密码”，你首次登录后须先修改密码 |
| 钉钉 / 飞书 / 企业微信等单点登录账号 | 无需平台密码，点登录页上对应的登录按钮即可 |

连续输错密码被临时锁定时，等锁定时间到后再试，或联系管理员解锁。

## 外部账号如何对应到平台用户

SSO / LDAP 登录成功后，平台按“匹配依据”（第三方 ID → 用户名 → 邮箱 → 手机号，由可靠到不可靠）寻找已有用户：

- 已绑定过的外部身份直接登录；
- 邮箱匹配只在**恰好匹配一个用户**且 IdP 没有声明“邮箱未验证”时才采用；手机号（与用户已绑定的短信两步验证号码比对）同样只在唯一匹配时采用；
- 找不到时按该登录方式的“首次登录策略”：仅限已有用户（拒绝登录）或自动创建用户（随机不可用密码，并按入组规则加入权限组 / 资源组）；
- **已停用的用户一律拒绝**；超级用户按设置可拒绝外部登录。

如果你用 SSO 登录后提示“账号不存在”，说明管理员选择了“仅限已有用户”，请先联系管理员建号。

## 两步验证（2FA）

是否需要两步验证取决于两点：你是否已经绑定，以及管理员是否开启了“强制两步验证”。

- 已绑定：账号密码（含 LDAP）通过后，还要输入 **TOTP 动态口令**（验证器 App，基于时间、SHA1、6 位、30 秒一变）或**短信验证码**（6 位，5 分钟有效，同一号码 60 秒内只能获取一次）；
- 未绑定但被强制：第一次登录时引导你绑定——TOTP 用验证器（Google 身份验证器 / Microsoft Authenticator 等）扫描二维码，无法扫码时手动输入页面上的密钥，输入一次口令确认后才算绑定成功；短信方式先填手机号再获取验证码，验证通过后自动登录；
- 通过浏览器跳转的 SSO 登录默认视为 IdP 已验证，不再做两步验证（管理员可开启“外部登录后仍要求两步验证”）；
- 同一个口令在同一个时间窗口内不能重复使用；验证码连续输错 5 次会作废，登录级别的失败次数超限则需要重新输入密码；
- 密码通过后到完成两步验证的中间态只保留 5 分钟，超时要重新输入密码。

换手机后验证器丢失：联系管理员在[用户页](#help/sysadmin)里“重置 2FA”（会删除你全部验证方式），然后重新绑定。

## 账号锁定

连续输错密码达到阈值（默认 5 次）后账号被锁定一段时间（默认 300 秒，时长由管理员设置），期间即使密码正确也无法登录。

- 为避免泄漏“账号是否存在”，所有失败（用户不存在 / 密码错 / 被停用 / 被锁定）都只提示同一句“用户名或密码错误”；
- 等锁定时间过后重试，或请管理员在[用户页](#help/sysadmin)里“解锁”（把失败计数清零）；
- 阈值与时长由管理员在“安全策略”里调整。

## 修改密码与会话

- 只有**本地账号**可以在头像菜单里修改密码（页面 `/account/password`）；LDAP / SSO 账号的密码在各自系统里维护，没有本地密码的账号打开“修改密码”页只会看到提示；
- 新密码要满足管理员设置的密码策略：至少 N 个字符（N 默认 9，由管理员设置），开启复杂度时需同时含字母、数字和特殊字符；不能是常见弱口令、纯数字，也不能与用户名、姓名、邮箱太相似，不能与当前密码相同；
- 修改成功后当前登录不受影响，其他设备上已登录的会话在到期前仍然有效；怀疑密码泄露请联系管理员处理；
- 管理员要求你先改密时（例如用“系统生成临时密码”重置过你的密码），登录后只能使用修改密码页，改完才能继续使用其他功能；
- 登录会话有有效期（由管理员设置，默认 300 分钟，每次请求自动续期，超过有效期没有任何操作才需要重新登录），默认关闭浏览器即退出；每次登录都会换发新的会话，不沿用旧会话。

## 账号绑定

入口：头像菜单里的“外部账号绑定”（`/account/bindings`）。把你的外部账号（钉钉 / 飞书 / OIDC 等）绑定到当前平台账号，之后可直接用它登录。

- 管理员在“登录认证 › 通用规则”里开放了“允许用户自行绑定 / 解绑外部账号”才能操作，否则这里只能查看已有的绑定，需要变更请联系管理员；
- 绑定时点“绑定 xxx”会跳转到身份提供方授权，完成后回到本页；同一个登录方式只能绑定一个外部账号，外部账号已绑定给别人时不能重复绑定；
- 解绑后，该外部账号下次登录时会按“匹配依据”（第三方 ID / 用户名 / 邮箱 / 手机号）重新匹配平台用户，匹配不到则不能登录。

## 登录认证（管理员）

菜单：**访问控制 › 登录认证**（仅超级用户）。自定义用户的登录验证方式：LDAP、OIDC、钉钉、CAS、飞书、Lark、Slack、企业微信都可以用来登录，可以同时启用多种，同一类型也可以添加多个（例如两套 LDAP、飞书和 Lark 各一个）；配置保存即生效，不用重启；密钥加密存储，页面不回显。

> 警告：启用前必须测试通过；配置已变更时需重新测试。本地账号密码登录永远保留给超级用户（`/login?local=1`），避免外部登录配错把自己锁在外面。

页面从上到下：

- **概览**：启用中、已停用、测试通过（x / 总数，有异常或配置已变更待重新测试时标出）、本地账号密码登录（开放 / 仅后门）四个数字；
- **已定义的登录方式**：固定第一行是内置的“本地账号密码”（不可停用或删除）。其余行可用“↑ / ↓”或拖动手柄调整登录页上的显示顺序；“配置”“测试”；“启用 / 停用”（停用后才能“删除”，删除会连配置与密钥一并清除，有用户通过它登录过时会再次确认）；
- **通用规则**：见下表；
- **登录页预览**：按当前已保存的设置画出登录页，只列出“启用且测试通过”的方式，停用或异常的不显示；多种方式同时启用时按上表顺序排列。每次打开登录页都会读取这里的配置，退出登录即可看到变化。

### 添加与配置

点“+ 添加登录方式”选类型、填名称（管理员看的，如“公司 SSO”），添加后进入配置，测试通过才能启用。配置里的通用项：

| 字段 | 说明 |
|---|---|
| 名称 / 登录页按钮文字 | 按钮文字留空时显示“使用 名称 登录”；LDAP 走账号密码表单，没有单独按钮 |
| 首次登录策略 | 仅已有用户（不自动创建，找不到就拒绝）或自动创建用户 |
| 默认权限组 / 资源组 | 只在“自动创建用户”时使用，可多选（按住 Ctrl / Shift）；留空则用“安全策略”里的“新用户默认权限组 / 资源组” |
| 每次登录同步更新姓名 / 邮箱 | 外部身份里的姓名、邮箱变化时同步到平台用户 |
| 登录后回填第三方 ID | 仅钉钉 / 飞书 / Slack 有（企业微信在用户资料里没有对应的通知 ID）；用于通知 @ 人，还需开启“通用规则”里的回填开关 |
| 回调地址 | 只读，格式为对外地址加 `/login/sso/<id>/callback`，填到身份提供方的应用配置里，可点“复制” |

各类型的连接参数：

| 类型 | 参数 |
|---|---|
| LDAP | 服务器地址；连接方式（LDAPS / StartTLS / 明文，不建议明文）；超时（秒，留空 = 10）；绑定 DN（查询账号）与绑定密码；用户搜索 Base 与过滤（如 `(sAMAccountName=%(user)s)`），或改用“用户 DN 模板”，两种方式二选一；是否校验服务端证书 |
| OIDC | Wellknown URL；Client ID / Client Secret；Scopes；签名算法（RS256 / ES256） |
| 钉钉 | AppKey / AppSecret；企业 CorpId（授权页限定企业，可空） |
| CAS | CAS 服务地址；协议版本（3 / 2 / 1）；是否校验服务端证书；强制 service URL 使用 https；退出时同时退出 CAS（全局登出：退出平台后跳转到 CAS 的登出地址） |
| 飞书 / Lark | App ID / App Secret；站点（飞书 open.feishu.cn / Lark 国际版 open.larksuite.com）；租户限制 tenant_key（可空） |
| Slack | Client ID / Client Secret；限制工作区 Team ID（可空）；使用 “Sign in with Slack”（OpenID Connect） |
| 企业微信 | 企业 CorpId、应用 AgentId、应用 Secret；授权方式（企业微信内免登 + 浏览器扫码 / 仅浏览器扫码） |

密钥类字段保存后不回显：留空表示不修改，已配置的会显示“已配置，留空不修改”，可点“清除已保存的密钥”在保存后清除。保存前会列出变更差异并二次确认，审计里也不记录密钥内容。

> 警告：修改连接相关的参数后，已启用的登录方式会被自动停用，之前的测试结果作废，需重新测试通过后才能再启用。

**用户属性映射**：把外部返回的字段对应到平台用户字段；留空使用输入框占位里的默认值，多个备选属性之间用竖线分隔，从前往后取第一个有值的。

| 平台字段 | 必填 | 说明 |
|---|---|---|
| 用户名 username | 是 | LDAP 留空 = 登录时输入的账号 |
| 姓名 display | 是 | 平台姓名最长 10 个字符 |
| 邮箱 email | 否 | |
| 手机号 phone | 否 | 匹配依据含“手机号”时使用 |

**匹配依据**：外部账号怎么找到平台里已有的用户。可以沿用“通用规则”里的全局设置，也可以只对这个登录方式单独设置；顺序固定为 第三方 ID → 用户名 → 邮箱 → 手机号，至少选一种。第三方 ID 指钉钉 UserID / 飞书 OpenID / Slack ID / 企微 UserID。

**入组规则**：按外部属性自动加入权限组 / 资源组。每条规则由“外部属性、比较（等于 / 包含）、值、加入的权限组、加入的资源组”组成；“每次登录都按规则同步”打开后，外部调整部门等属性，平台权限随之变化（只增不减，不会移除手工加入的组）。没有命中任何规则时，使用上面的默认权限组 / 资源组，再没有就用系统设置里的全局默认。

### 测试

测试使用已保存的配置；弹窗里有未保存的修改时，点“测试”会先保存（同样需要确认）。

- **LDAP**：填测试账号和密码（密码只用这一次、不保存）时，用该账号走一遍登录校验；测试账号可留空，此时只测连接与查询账号；
- **其他类型**：“测试连接”只检查元数据 / 凭据；完整的登录流程要点“测试登录（打开授权页）”，在新窗口完成授权后回到弹窗点“刷新结果”。测试登录不会创建用户、不会建立会话、不会写入登录绑定，也不会把你切换成那个账号。测试没有通过时，结果里逐行列出原因。

### 通用规则

| 设置项 | 默认 | 说明 |
|---|---|---|
| 本地账号密码表单 | 折叠 | 始终显示（在 SSO 按钮下方）、折叠（登录页“或使用平台账号”展开）或隐藏（仅 `/login?local=1` 可用，超级用户后门） |
| 外部账号匹配已有用户的依据 | 用户名、邮箱 | 第三方 ID、用户名、邮箱、手机号；全局默认值，每个登录方式可在自己的“配置”里单独覆盖；邮箱只在唯一匹配且 IdP 没有声明邮箱未验证时才采用，手机号同样只在唯一匹配时采用 |
| 超级用户只能本地登录 | 开 | 超级用户不参与外部登录；取消后外部身份匹配到超级用户时将允许登录，请确认身份提供方的账号安全 |
| 外部登录后仍要求两步验证 | 关 | 默认认为身份提供方已验证；关闭时外部登录成功不再校验动态码 |
| 登录后回填第三方 ID | 开 | 登录成功后把第三方 ID 回填到用户资料，用于通知 @ 人 |
| 允许用户自行绑定 / 解绑外部账号 | 关 | 用户在“账号绑定”页 `/account/bindings` 操作 |

保存通用规则前同样会列出变更差异，确认后立即生效。

## 安全策略（管理员）

菜单：**访问控制 › 安全策略**（仅超级用户）。把分散的安全项集中在一页：保存前会列出变更差异并二次确认，确认后立即生效（本实例立即，其他实例最多 10 秒）。降低安全强度的修改（缩短密码长度、关闭强制 2FA、开放注册、放宽锁定、关闭 JWT OTP、关闭水印、清空 API 白名单、会话超过 24 小时等）会给出风险提示，不阻止保存。外部登录（LDAP / OIDC / 钉钉 / CAS / 飞书 / Slack / 企业微信）在“登录认证”里配置。

页面顶部是锁定策略、两步验证（已绑定账号数 / 总数）、密码策略、会话 / JWT 四个概览数字，底部“已定义的登录方式”是只读摘要。一次登录依次经过：

1. 输入账号：本地账号密码，或点登录页上的外部登录按钮（SSO）；
2. 锁定检查：连续输错达到阈值就锁定一段时间，提示语不区分原因；
3. 验证身份：本地密码（符合最小长度）或外部认证；超级用户只走本地；
4. 两步验证：强制时未绑定先绑定、已绑定输入动态码；自愿时只有已绑定的用户输入动态码；
5. 建立会话：按会话有效期滑动续期，可设为关闭浏览器即退出；
6. 进入系统：页面叠加水印（如已开启），所有操作写入审计。

### 账号安全与会话

| 设置项 | 取值范围 | 默认 | 说明 |
|---|---|---|---|
| 登录失败锁定次数 | 1–100 | 5 | 连续输错几次后锁账号 |
| 锁定时间（秒） | 10–86400 | 300 | 锁定持续多久 |
| 强制两步验证 | 开 / 关 | 关 | 开启后登录时未绑定的用户必须先绑定 |
| 开放用户自助注册 | 开 / 关 | 关 | 开启后登录页出现“没有账号？注册用户”；新用户按默认权限组 / 资源组入组 |
| 密码最小长度 | 6–64 | 9 | 已有账号不受影响，新建与改密按新规则 |
| 密码需含字母、数字、特殊字符 | 开 / 关 | 关 | 复杂度要求 |
| 会话有效期（分钟） | 5–43200 | 300 | 滑动续期：每次请求自动延长，超过这么久没有任何操作才需要重新登录；页面自己定时发的后台请求（如顶栏值班信息的刷新）不算操作，不延长 |
| 关闭浏览器即退出 | 开 / 关 | 开 | 会话不持久化 |
| JWT 有效期（小时） | 1–720 | 4 | access 令牌有效期 |
| JWT 登录要求动态口令（OTP） | 开 / 关 | 关 | 开启后 `/api/v1/auth/login` 要求已绑定两步验证的用户附带动态口令 `otp` |
| API 用户白名单 | 用户多选 | 空 | 为空表示不限制；非空时只有名单内用户的 JWT 能调用 API，按住 Ctrl / Shift 可多选 |
| 新用户默认权限组 / 资源组 | 多选 | 空 | 新用户 = 自助注册或外部登录首次自动创建的用户；外部登录方式单独设置了默认入组的，以那里为准 |

> 注意：锁定次数与时长在“平台设置 › 系统配置”的“登录与安全”分组里也能改（键 `security.login_lock_attempts` / `security.login_lock_seconds`），该页允许的范围更宽（1–1000 次、1–2592000 秒）；本页按上表范围校验。两处写的是同一份数据。

### 页面水印

仅超级用户可定义。启用后在每个页面叠加水印，截图 / 拍屏外泄时可追溯到具体的人；用户不能自行关闭或修改。

| 设置项 | 取值范围 | 默认 | 说明 |
|---|---|---|---|
| 启用页面水印 | 开 / 关 | 关 | 总开关 |
| 水印内容 | 最长 60 字 | `{姓名}（{账号}）{时间}` | 模板，点变量按钮插入到光标处；变量有 `{账号}` `{姓名}` `{部门}` `{IP}` `{日期}` `{时间}`；必须含 `{账号}` 或 `{姓名}`，否则截图无法追溯到具体的人 |
| 附加文字 | 最长 40 字，可空 | 空 | 显示在第二行，如“内部资料 严禁外传” |
| 透明度 | 3%–30% | 14% | 太淡拍屏看不清，太浓影响阅读，建议 10%–18% |
| 字号 | 12–28 px | 14 | |
| 倾斜角度 | -60 到 0 度 | -22 | 0 为水平，负数向上倾斜 |
| 疏密 | 紧凑 / 标准 / 宽松 | 标准 | |
| 颜色 | 跟随主题 / 灰色 / 红色 / 蓝色 | 跟随主题 | 跟随主题：深色主题用浅字，明亮 / 护眼主题用深字 |

右侧“效果预览”用的是你自己的账号信息，其他用户看到的是他们自己的；“全页预览 5 秒”临时显示整页水印，不保存。水印层被删除、隐藏或改样式会自动恢复并记审计（动作“水印篡改”）。

### 两步验证短信服务

服务商可选关闭（仅 TOTP）、阿里云、腾讯云。短信验证码 6 位，5 分钟有效，同号码 60 秒内不能重复获取，错误 5 次作废，同一号码每小时最多发送 10 条。

- 阿里云：AccessKey ID / AccessKey Secret、短信签名、模板编号、模板变量名（默认 `code`）；腾讯云：SecretId / SecretKey、短信签名、模板 ID、SDK AppID；
- 密钥永不回显，留空提交表示不修改；
- “发送测试短信”使用**已保存**的配置：改了参数请先点右上角“保存配置”再测试；
- 未配置服务商时用户不能绑定短信验证。

## 通过 API 调用

脚本和第三方系统可以用 JWT（用户名 + 密码换取令牌，接口 `POST /api/v1/auth/login`）调用接口：受锁定与“API 用户白名单”约束，默认**不走**两步验证；管理员可开启“JWT 登录要求动态口令（OTP）”，此时已绑定 TOTP 的用户必须在请求里带 `otp` 字段。浏览器会话的非 GET 请求需带 `X-CSRF-Token`；脚本用 `Authorization: Bearer <JWT>`。

## 审计与安全说明

| 项 | 说明 |
|---|---|
| 审计动作 | 登入、登入失败、账号锁定、退出登录、修改密码（含失败）、注册用户、2FA 绑定 / 解绑 / 验证失败过多、SSO 登录、水印篡改，均写入系统审计，类别为“登录认证” |
| 敏感信息 | 审计、日志和变更差异里不记录密码、密钥、令牌与授权码；密钥类配置加密存储、接口不回显 |
| 防枚举 | 登录失败提示语不区分“用户不存在 / 密码错 / 被停用 / 被锁定”，对不存在的账号同样执行密码哈希计算，避免用响应时间判断账号是否存在 |
| 会话 | 每次登录换发新会话；管理员停用用户或修改超级用户标记后，最长约 10 秒在所有请求上生效 |
| 测试登录 | 管理员的“测试登录”不创建用户、不建立会话、不写绑定 |

## 常见问题与排障

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 登录提示“用户名或密码错误”，确认密码无误 | 账号被锁定、被停用，或 LDAP / SSO 账号走了本地表单 | 等锁定时间过后重试，或联系管理员；外部账号请用对应的登录按钮 |
| 登录页没有本地账号表单 | 管理员把表单设为隐藏 | 超级用户用 `/login?local=1`；普通用户用单点登录按钮 |
| SSO 登录后提示账号不存在 | 登录方式是“仅限已有用户”，且没有匹配到平台用户 | 联系管理员建号，或核对邮箱 / 用户名是否一致 |
| 验证器口令一直不对 | 手机时间不准；口令在同一窗口内已用过 | 校准手机时间，等下一个 30 秒再输入 |
| 收不到短信验证码 | 未配置短信服务商、号码格式不对、60 秒内重复获取、每小时已达 10 条 | 检查提示语；联系管理员核对短信服务配置 |
| 登录方式不能启用 | 没有测试通过，或连接参数改动后测试结果已作废 | 在配置弹窗里重新测试 |
| 登录方式启用后登录页没有按钮 | 登录页只显示“启用且测试通过”的方式 | 在页面下方“登录页预览”核对 |

## 验证状态与已知限制

| 项 | 状态 |
|---|---|
| 本地账号登录、两步验证（TOTP 与预置短信记录）、账号锁定、安全设置读写、会话与 JWT 有效期、API 白名单、水印、本地表单三种模式 | 在真实 MySQL 与假外部系统上通过冒烟验证 |
| OIDC、CAS、LDAP 的授权码 / 票据 / 绑定与匹配流程 | 只用假 IdP / 假 LDAP（明文）验证；LDAPS / StartTLS / 证书校验、AD 的真实行为、referral 与分页未验证 |
| 钉钉 / 飞书 / Lark / Slack / 企业微信 | 只验证了配置校验、密钥加密、授权跳转与状态校验；令牌交换、用户信息、测试连接未与真实服务联调 |
| 阿里云 / 腾讯云短信 | 只测了接口层，真实发送未验证 |
| HTTPS / 反向代理下的 Cookie（`Secure`） | 未验证 |
| 短信验证码保存在进程内存 | 服务重启后未使用的验证码作废；多实例同时运行时验证码不共享 |
