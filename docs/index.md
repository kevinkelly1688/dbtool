## 4. 文档约定

- **事实来源**：文档中的行为描述以代码为准；与代码不一致时以代码为准并应修正文档。
- **验证状态**：文档区分"已验证"、"仅假后端验证"、"未验证"，不会把未验证写成已验证。
- **提示块**：`注意`（需留意的细节）、`警告`（高危或不可逆）、`提示`（便利做法）。
- **术语**：实例、资源组、权限组、SQL 工单、数据脱敏、元数据库（表前缀 `dbt_`）、目标库（被管理的数据库）。
- **章节号**：文档的章节号会随结构调整，跨文档引用请以标题为准。
- **链接**：以 `../` 开头的链接指向仓库里的文件（`README.md`、`deploy/PACKAGING.md`、站内帮助源文件），发布包里没有这些文件；其余链接在仓库和发布包里都能打开。
