# 常见问题

## 权限与菜单

### 看不到某个菜单或按钮

没有对应权限。先看按钮悬停提示里写的权限码，然后：

1. 到「系统管理 › 权限组管理 › 按用户查看有效权限」确认这个码的来源或为什么缺失；
2. 在查询类场景到[权限管理](#help/qpriv)申请库表权限；
3. 其余联系管理员或所在资源组负责人授权。

按钮显示"仅超级用户可用"表示它是锁定码，权限组授不出去，只能由管理员操作。

### 为什么我只能看到部分实例

实例按资源组关联：你所在资源组没关联的实例不会出现。需要新实例请联系管理员把它加入你的资源组。带 `read_view` 标签的实例只能访问 `v_` 开头的视图。

### 刚被授权但页面没变化

真实系统权限最长约 15 秒生效，刷新页面即可。

## SQL 上线

### 工单提交后没有人审批 / 卡住了

常见原因：

1. 审批流的某一级**没有人**有审批权限（管理员在"审批流程配置"里能看到警告）；
2. 你自己是那一级**唯一的**审批人——不能自己审批自己；
3. 审批人不在工单所属的资源组里。

### SQL 检查报"降级"或只有本地检查

goInception 没配置或不可用，只做词法级检查，没有影响行数和备份。联系管理员配置，详见[系统管理](#help/sysadmin)。

### 提交时提示"DDL 与 DML 不能混提"

把 DDL 和 DML 拆成两张工单。注意 `DELETE` 也被归为 DDL 类。

### 执行有异常，要怎么办

执行是"失败即停"：已成功的语句已生效，后面的标"未执行"。到目标库确认现状；开启了备份的可以[查看回滚语句](#help/sqlworkflow)；修复语句另开新工单。

### 为什么不能终止"执行中"的工单

SQL 已发往目标库，无法安全撤回。大表改动请使用在线改表（OSC）并通过暂停 / 终止控制。

## 查询与导出

### 查询提示没有权限

先到[权限管理](#help/qpriv)申请库表权限，审批通过后即时生效。

### 查询结果被截断

触发了行数上限。上限取你在这些表上权限里的最小限制。需要更多数据请走[数据导出](#help/export)（默认单次 ≤ 1 万行）。

### 导出下载不了

缺少下载权限（`export.download`），或文件已过保留期，或工单还没执行完。重新提交即可。

### 在线查询里为什么不让我 `SELECT *`

管理员开启了禁用通配符。从左侧对象树点表名可以自动展开字段。

## 登录与账号

### 登录时被要求输入验证码

已开启两步验证。换手机后验证器丢失，联系管理员"重置 2FA"后重新绑定。

### 忘记密码怎么办

按账号类型找回：LDAP / AD 域账号到公司统一身份平台找回；本地账号请管理员在用户管理里重置密码（可生成临时密码，首次登录须先改密）；钉钉 / 飞书 / 企业微信等单点登录账号没有平台密码，点登录页上对应的登录按钮即可。详见[登录章节](#help/login)。

### 账号被锁定

默认连续输错 5 次会锁定 300 秒（5 分钟），登录页对这种情况和"密码错误"提示同一句"用户名或密码错误"。等待锁定时间过后重试，或请管理员在用户管理里"解锁"。详见[登录章节](#help/login)。

### 设置密码时提示"密码太短"或"需要同时包含字母、数字和特殊字符"

新建用户、重置密码、修改密码都要满足"登录与安全设置"里的密码策略：最小长度（默认 9 位）、复杂度（默认不要求，开启后须同时含字母、数字和特殊字符），并且不能是常见弱口令、纯数字，不能包含用户名等。提示里的数字是当前生效的最小长度；用户管理表单上写的"至少 9 位"是固定文案，不随设置变化。

### SSO 登录后提示账号不存在

登录方式被设为"仅限已有用户"，且按邮箱 / 用户名没有匹配到平台用户。联系管理员建号或检查邮箱是否一致。

## 性能工单

### 工单为什么突然被重开了

同一条 SQL 在关闭后再次变慢且影响超过阈值，系统会自动重开。确属误报请 DBA 使用"误报关闭"，之后不再重开。

### 延期按钮是灰的

可能已达该级别的最大延期次数（P0 不允许延期），或已有待审批的延期 / 豁免申请，或工单不在计时状态。

### SLA 为什么没在计时

只有待分派、待受理、处理中三种状态计时；待验证和豁免审批中会暂停。

## 数据归档

### 归档任务的"提交申请"按钮是灰的

提交前必须先"试运行"，且结果有效：红色检查项（如时间列没有索引、被外键子表引用、备份存储异常、该资源组没有审批流）不能提交；黄色警告需要勾选"已知晓"，命中超过表的 30% 需要另外勾选"已确认大批量"（它是黄色，不是红色阻断）；试运行后改了来源 / 条件 / 备份去向 / 单次上限，或超过 7 天，结果会失效，需重新试运行。按钮旁会写明具体原因，详见 [数据归档](#help/archive)。暂时不想提交，可以先"保存草稿"（不要求试运行）。

### 归档任务提交不了，提示没有审批流

所选资源组没有配置"数据归档申请"的审批流（或审批流里没有任何有审批权限的权限组）。请管理员在「审批流程配置」里为该资源组配置，详见 [数据归档](#help/archive)。

### "立即执行"被拒绝或本次被跳过

常见原因：任务不是"已启用"；源表有待执行 / 执行中的 SQL 上线工单；同一实例的归档运行已达并发上限（默认 2）；上一次运行还没结束；备份存储已停用或最近一次测试失败；保留天数低于策略的最小保留天数；当前不在执行窗口内（可勾选"忽略执行窗口"，负载保护仍然生效）。提示里会写明具体原因。源表结构指纹与审批时不一致不会在点击时被拒绝：运行会先启动，很快以"结构变更暂停"结束，任务被置为已暂停，需重新试运行并重新提交审批。

### 任务被自动暂停了

连续多批失败、备份校验不一致、收尾上传文件失败或源表结构变化都会自动暂停，原因写在任务详情里。处理完再"恢复任务"；结构变更暂停需要重新试运行并重新提交审批，不能直接恢复。

### 归档运行没跑完就结束了，是失败吗

不一定。"窗口结束中断""负载中断""已达上限"都是安全停止，已处理的数据都已备份并校验，断点已记录，**下次接着跑**；"已跳过"表示到点时有前置条件不满足，本次没有执行。只有"失败""校验失败""中断"需要排查，且"失败"和"校验失败"都不会删除未备份的源数据。

## 其他

### 页面时间差 8 小时

反馈给管理员，时区配置与原系统不一致。

### 原型里的数据刷新后消失了

原型是纯前端模拟，所有操作只改内存，刷新页面即还原；这是预期行为。
