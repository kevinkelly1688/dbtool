# 数据字典

菜单：SQL 查询 › 数据字典。实时从目标库读取元数据，按对象类别浏览表结构、索引、建表语句和注释，不需要任何库表授权（只要实例在你的可见范围内）。

## 浏览

1. 选择实例和库，库列表会自动去掉系统库（mysql / information_schema / performance_schema / sys 等），并遵守实例的库名过滤规则；
2. 选择类别：**表 / 视图 / 触发器 / 存储过程 / 函数 / 定时任务**；对象按首字母分组，带 A–Z 快速跳转；
3. 用上方搜索框按**名称或注释**过滤；表列表带「分区表」「敏感列 N」标记，类别页签上的数字是该类别的对象数；
4. 点对象名查看详情。

### 详情内容

| 对象 | 内容 |
|---|---|
| 表 | 表信息（引擎、行格式、行数估算、数据 / 索引大小、自增值、字符集、创建 / 更新时间、注释）、列信息（类型、可空、默认值、注释；敏感列带「敏感」标记，并在表信息下方列出，在线查询结果中这些列按脱敏规则显示）、索引信息（按索引合并列）、建表语句（带复制按钮） |
| 视图 / 触发器 / 存储过程 / 函数 / 定时任务 | 基本信息和定义（`SHOW CREATE`） |

> 行数、大小是引擎的估算值（MySQL 系取自 `information_schema`），不是精确 `COUNT(*)`。

## 导出 HTML

点「导出 HTML」（`dict.export`，高危）生成一份**单文件、离线可读**的字典：样式内联、不引用外部资源、不含脚本，带目录锚点，含每张表的注释、列和索引。

- 页面右上角的「导出范围」选当前库或整个实例：普通用户导出当前库；**整个实例导出（ZIP，每库一个 HTML）仅超级用户**；PostgreSQL / MongoDB / ClickHouse 实例同样可导出；
- 每次导出都会先写审计日志，写不进去就取消导出；单次最多 200 个库、每库最多 5000 个对象。

## 支持的实例类型

| 类型 | 开放的对象类别 |
|---|---|
| MySQL / PolarDB / PolarDB-X | 表、视图、触发器、存储过程、函数、定时任务 |
| SelectDB / Doris / ADB | 仅表 |
| SQL Server | 表、视图、触发器、存储过程、函数（暂不支持 Agent 作业；建表语句暂不生成） |
| PostgreSQL | **表、视图**两个页签（物化视图归入视图）：表名带 schema，详情有表信息（类型、属主、访问方法、估算行数、表 / 索引大小、注释）、字段（含 IDENTITY）、索引、**近似 DDL**（开头声明“近似 DDL”，不含属主、权限、触发器等）；行数是 `pg_class.reltuples` 的估算（尚未统计过的表不显示），没有创建 / 修改时间 |
| MongoDB | **集合、视图**两个页签：字段与类型是**采样前 100 个文档**推断的（多种类型用 `\|` 连接，不是 schema，没出现在样本里的字段不会列出）；文档数是 collStats 的元数据计数，非精确；没有表注释，也不记录创建 / 修改时间；“建表语句”是集合选项和索引定义的 JSON 描述，**不是可执行语句** |
| ClickHouse | **表、视图**两个页签（字典算表）：详情有引擎、完整引擎定义、分区键 / 排序键 / 主键、行数 / 大小（非 MergeTree 可能为空，显示“-”）、字段、索引（primary / 跳数索引）和服务端生成的真实 DDL；不记录创建时间，“更新时间”是最近一次 DDL |
| Oracle 等其它类型 | 暂不支持，实例下拉里灰显 |

## 只读视图实例

带 `read_view` 标签的实例按保守策略处理，对所有人（含超级用户）生效：只开放"视图"类别；只显示 `v_` 开头的视图；详情只展示列信息，**不展示视图定义**（定义会暴露底层表）；导出只含这些视图的列信息。

## 权限

| 权限码 | 说明 |
|---|---|
| `dict.view` | 查看表 / 视图 / 过程等元数据 |
| `dict.export` | 导出 HTML 字典（高危） |

> 原型体验：rd_zhao 能浏览但导出按钮置灰；dba_li 可导出。打开 mysql-order-view 看只读视图的限制；pg-order-prod-m（schema 分组的表名、估算行数、近似 DDL）、mongo-order-prod（采样字段）、ch-order-olap（引擎 / 分区键 / 排序键、字典）可看新类型的字典；这三类实例带 `read_view` 标签时，字典同样提示“不支持只读视图模式”。
