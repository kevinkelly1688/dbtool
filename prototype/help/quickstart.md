# 快速入门

DB Tool 围绕 MySQL / MariaDB / SQL Server 等实例，提供 **SQL 上线审核、在线查询、慢日志、SQL 优化、性能工单、实例管理** 和一套按按钮粒度控制的权限体系。本手册同时服务于开发、测试、组长（审批人）、DBA 和管理员五类角色，每一章都按"你能做什么、怎么做、有什么限制"来写。

> 当前打开的是**可交互原型**：数据均为模拟，操作只改内存，刷新页面即还原；但菜单、权限码、状态流转、校验规则与真实系统保持一致。原型里可用 admin 超级用户 / dba_li DBA / tl_wang 组长 / rd_zhao、rd_zhou 研发 / qa_sun 测试 / auditor_chen 审计 这些账号体验不同角色，密码统一为 `Dba@2026`，验证码为 `123456`。

## 界面介绍

登录后的页面由三部分组成：

- **侧栏（左）**：按分组列出你有权限打开的菜单，分组可折叠；带数字的角标是你的待办（SQL 上线 / 权限管理 = 等你审批的单子，性能工单 = 你的待办，橙色表示已有超时）。真实系统里这一块是顶栏的点击下拉菜单，内容与分组完全相同。
- **顶栏**：左侧是当前页面标题和所属分组；右侧依次是「? 帮助」（打开**当前页面对应的手册章节**）、主题切换、身份切换和头像菜单。
- **内容区**：当前页面。表格外层带横向滚动，窗口窄于 900 px 时布局会自动折叠。

头像菜单里可以查看"个人信息与权限"（你属于哪些权限组、哪些资源组、能看到几个实例）、修改密码（仅本地账号）、查看两步验证状态、退出登录。

页面里只保留操作本身，字段含义、规则、限制和注意事项都写在本手册里：在任何页面点顶栏的「? 帮助」，就会打开该页面对应的章节；章节内可以用左侧的搜索框做全文检索。

## 首页

登录后默认进入首页（工作台），汇总你权限范围内需要处理的事项；没有权限的区块不显示。

| 区块 | 内容 |
|---|---|
| 页头 | 当前权限组、部门、资源组、日期和上次登录时间；右侧「提交 SQL 工单」直达提交页（需要 `sqlworkflow.submit`） |
| 顶部 KPI | **待我审批**（没有待办时显示"没有待审批事项"）、**进行中工单（我的 / 全部）**（我提交的、还没结束的 SQL 工单 / 你可见范围内全部进行中的工单）、**性能工单待办**（有超时的会标出个数）、**我可见的实例**（并汇总状态异常的个数） |
| 我的待办 | 页签「待我审批」（SQL 上线、查询权限、数据归档）/「我提交的」/「性能工单」，点一行进入详情；标题旁的数字是三个页签的合计；「我提交的」里执行有异常的工单、「性能工单」里已超时的会标「需处理」 |
| 快捷入口 | 按你的权限列出可进入的功能；没有任何可用入口时提示联系管理员授权 |
| 近 7 日 SQL 工单 | 每天提交的工单数，标题旁是 7 日合计；超级用户和持有 `sqlworkflow.view_group` 的人统计可见范围内全部，其他人只统计自己提交的 |
| 实例健康 | 你可见的实例（最多列 9 个）及状态：正常、连接数偏高、连接失败；没有可见实例时需联系管理员把你加入资源组；右上角「实例列表」需要 `instance.view` |
| 最近动态 | 超级用户和持有 `audit.view` 的人看全平台，否则只看自己的操作；右上角「系统审计」需要 `audit.view` |
| 平台状态 | goInception 检查服务、通知机器人、定时调度器、元数据库、按钮权限模式 |

## 菜单分组

| 分组 | 包含的页面 | 主要使用者 |
|---|---|---|
| 工作台 | 首页（我的待办、快捷入口、实例健康、最近动态、平台状态） | 所有人 |
| SQL 审核 | SQL 上线（工单）、SQL 分析 | 研发 / 测试 / 组长 / DBA |
| SQL 查询 | 在线查询、查慢日志、分区维护、数据归档、数据导出、数据字典、权限管理（权限申请）、查询权限 | 研发 / 测试 / 组长 / DBA |
| SQL 优化 | 优化工具、慢查日志 | 研发 / DBA |
| 性能工单 | 工单列表、团队排行榜，以及管理员用的采集配置 / 团队配置 / SLA 策略 | 研发 / DBA |
| 实例管理 | 实例列表、会话管理、数据库管理、账号管理、参数配置、性能巡检 | DBA |
| 系统管理 | 审批流程配置、资源组管理、用户管理、权限组管理、登录方式、登录与安全设置、系统审计、goInception 配置、Redis 上线规则、通知渠道 | 管理员 |
| 帮助 | 使用手册 | 所有人 |

**界面里没有某个菜单，说明你没有对应权限**（菜单是否显示取决于你是否持有该页面的"查看类"按钮码，见 [按钮级权限](#help/btnperm)）。找管理员或所在资源组的负责人开通。

## 按钮的三种状态

页面里所有会产生副作用的按钮都由权限码驱动，你会看到三种形态：

| 形态 | 外观 | 含义 |
|---|---|---|
| 可用 | 正常按钮，悬停提示权限名；高危按钮悬停会注明"（高危）" | 你持有该权限码 |
| 无权限 | 置灰并带 🔒，悬停提示"无权限：需要「xxx」（权限码）" | 你没有该码；"仅超级用户可用"表示该码是锁定码，权限组也授不出去 |
| 隐藏 | 按钮直接不出现 | 管理员在设置里把"无权限按钮"设为隐藏 |

**高危按钮**（执行上线、终止会话、删除、授权回收等）点击后不会立刻生效：先弹出二次确认，说明将要做什么，部分操作还需要键入指定文本（例如库.表名、Binlog 文件名）才能点确认。所有写操作都会记入[系统审计](#help/sysadmin)。

> 权限刚被管理员修改后，真实系统最长约 15 秒生效；原型里切换身份后立即生效。

## 你能看到哪些实例

实例的可见范围由**资源组**决定：你所在资源组关联的实例才会出现在各页面的实例下拉里。例外是持有"查看 / 查询全部实例"权限（`query.admin_run`）的人以及超级用户，他们看得到所有启用的实例。

演示数据里有 4 个业务资源组（订单中心、支付中心、用户中心、数据平台），例如 rd_zhao 只属于订单中心，只能看到订单相关实例；qa_sun 属于订单中心和用户中心；dba_li、admin 看全部。带 `read_view`（只读视图）标签的实例，**所有人（含管理员）**只能查询、导出、浏览以 `v_` 开头的视图。

## 体验不同角色（身份切换演示）

原型顶栏右侧有一个身份下拉框，不用退出登录就能切换：

| 账号 | 角色 | 建议体验 |
|---|---|---|
| admin | 超级用户 | 全部菜单；系统管理里的锁定类按钮只有他能点 |
| dba_li | DBA | 审批 / 执行 SQL 上线、实例管理、性能工单处理 |
| tl_wang | 组长 | 审批本组 SQL 工单和查询权限申请，不能执行上线 |
| rd_zhao / rd_zhou | 研发 | 提交工单、在线查询、申请权限、受理性能工单 |
| qa_sun | 测试 | 提交工单、在线查询、导出 |
| auditor_chen | 审计 | 只读审计日志与全部工单 |

切换后侧栏、角标和按钮会立即按新身份重新计算——这是对照各权限组差异最快的办法。

## 主题与水印

头像菜单或顶栏可在 **明亮 / 深空 / 护眼** 三套主题间切换，选择保存在浏览器本地。页面水印（默认是“姓名（账号）时间”）由超级用户在[登录与安全设置](#help/sysadmin)里统一定义，用于截图溯源；你只能看到它，不能自行关闭或修改。

## 一次典型的上线流程

1. 研发在 **权限管理** 申请库表查询权限，在 **在线查询** 里确认数据；
2. 研发在 **SQL 上线** 提交变更 SQL，系统用 goInception 检查；
3. 工单按资源组审批流逐级审批（常见：组长 → DBA）；
4. DBA（或有权限的提交人）选时间执行，必要时下载回滚语句；
5. 上线后慢 SQL 由系统自动转成 **性能工单**，研发按 SLA 处理。

各环节的细节见 [SQL 上线](#help/sqlworkflow)、[权限申请与查询权限](#help/qpriv)、[性能工单](#help/perf)。遇到问题先看 [常见问题](#help/faq)。
