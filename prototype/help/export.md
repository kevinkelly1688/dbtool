# 数据导出

菜单：SQL 查询 › 数据导出。在线查询有行数上限且不能下载，需要拿一批数据（对账、报表、迁移）时，通过**导出工单**：写一条只读查询 → 审批 → 执行 → 下载压缩包。导出工单与 SQL 上线共用同一套审批、定时和通知机制。

## 提交导出

1. 点「提交导出」（`export.submit`），选择目标实例和库；页面会显示实例所属的资源组及其审批流，导出工单与 SQL 上线共用同一套审批流；
2. 选择**导出格式**：CSV / XLSX / JSON / XML / SQL（INSERT 语句）；
3. 写**一条**只读查询，点「检查并统计行数」；编辑器上方的「合法查询 / 无条件全表 / 写入语句」三个示例可以快速体验检查结果；
4. 通过后填写名称提交，进入审批流。**定时执行**可不填：勾选后填写时间，审批通过后到点自动导出；不填也可以在审批通过后由执行人在详情页设置。

检查结果每个实例一行，显示通过 / 警告 / 错误和待导出行数；行数进度条超过上限的 80% 变黄，超限变红。语句或实例变更后，之前的检查结果作废，需要重新检查。

### 语句与行数规则

- 只允许**一条** SELECT / WITH；拒绝 `update` / `delete` / `insert`、`INTO OUTFILE / DUMPFILE`、`FOR UPDATE`、`LOCK IN SHARE MODE`、`load_file` 等危险函数、`;` 夹带第二条语句、查询 `mysql.user`；SQL Server 另外拒绝 `exec` 与 `select ... into`；
- 系统会先统计行数（`SELECT COUNT(*) FROM (你的查询)`），**超过上限（默认 10000 行）判错，不允许提交**——请加条件或拆分；
- SQL Server 的 `DECLARE / SET @变量` 批处理无法预统计，会给出警告，行数限制留到执行时兜底；
- 实例必须带"可读"标签；带 `read_view` 标签的实例**所有人**只能导出 `v_` 视图；
- 导出工单不能跳过检查、不支持手工执行，也不会被自动审核规则自动通过，**必须有人审批**。

```sql
-- 导出某天的退款流水
SELECT refund_no, order_no, amount, status, created_at
FROM pay_db.refund_record
WHERE created_at >= '2026-10-01' AND created_at < '2026-10-02';
```

## 审批与执行

- 审批流沿用资源组里配置的"SQL 上线"审批流，审批人规则同[SQL 上线](#help/sqlworkflow)（不能自审）；
- 审批通过后，有执行权限的人点「立即导出」或设置定时导出（时间须晚于当前，定时期间可取消）；执行方式固定为原生执行：在目标实例上执行查询并生成文件；
- 导出文件按审批通过后、执行时的实时数据生成；查询在目标实例执行，LIMIT 上限为"行数上限 + 1"：多出的一行用来发现"执行时数据已经超限"，超限会直接中止，**不会把超限的数据写出去**；单次查询最长 60 秒；
- 结果打包为 zip：单实例一个文件，批量时每个实例一个文件，批量按实例逐个执行（MySQL 串行、SQL Server 并发），详情页显示进度条。

| 格式 | 说明 |
|---|---|
| CSV | UTF-8，所有字段加引号，NULL 写成 `null` |
| XLSX | 全部按文本单元格，避免长数字和前导零被 Excel 改写 |
| JSON | 数组，每行一个对象，键保持列顺序 |
| XML | 每行一个 `<row>`，NULL 为 `(null)` |
| SQL | `INSERT INTO your_table_name (...) VALUES (...);` |

> 导出结果**不做脱敏**，请只导出业务确实需要的列，并遵守公司的数据安全规范。

## 下载

在工单详情点「下载」（`export.download`，高危），状态须为"已正常结束"或"执行有异常"。点击后先弹高危确认，提示文件含未脱敏的业务数据、下载会写入审计日志。

- 需要同时满足：持有下载权限、能看到这张工单、文件名取自这张工单自己的记录；
- **每次下载都会写入审计日志**（包括失败的下载）；
- 文件在服务端有保留期，过期后需要重新提交；文件已被清理时会提示"文件不存在"，下载记为失败。

> 原型体验：qa_sun 默认带 `export.download`；rd_zhou 通过"单独授权"获得了下载权限，而 rd_zhao 没有，可对比两者的下载按钮。

## 批量导出

同一条查询在多个实例上各导出一份（需要 `export.submit_batch`，实例类型受管理员限制，演示里是 SQL Server）：

- 提交页勾选"批量导出"后，在「其余实例」里选择与主实例**同类型**的可见实例，**至少选 2 个实例**（含主实例）；每个实例要存在所选数据库、且待导出行数不超过上限，预检不通过的实例需取消勾选后重新检查；
- 每个实例一个文件，统一打成一个压缩包；
- **部分失败**：成功实例的文件仍可下载，工单标为"执行有异常"，汇总写明哪些实例没导出（异常实例不在压缩包里）；全部失败则不生成文件；
- **重试**失败实例：新文件会合并进同一个压缩包，其余实例已导出的文件不会丢；全部成功后变为"已正常结束"；
- **关闭**失败实例：不再计入工单成败，也不会再有文件；其余实例都成功时工单变为"已正常结束"；
- 审批后被删除的实例会写"实例已不存在，跳过导出"，不影响其他实例。

> 原型体验：批量导出时勾选 mysql-dw-prod-s，该实例导出会超时，可用来演示失败后的重试 / 关闭。

## 导出工单列表

菜单：SQL 查询 › 数据导出。

- 顶部统计卡：等待审批、待执行（审核通过）、执行中、执行有异常；
- 页签「普通导出 / 批量导出」（批量页签需要 `export.view_batch`），可按状态筛选，勾选「只看待我审批」只显示轮到你审批的工单，搜索框匹配工单号、名称、提交人和库；
- 可见范围：普通用户只能看到自己的导出工单，组长 / DBA / 审计可看到所在资源组内的全部工单；详情页同样只有本人、同资源组有审批权限的人和审计能打开，其他人看到的是"工单不存在"；
- 详情页的审批流程卡片显示各级进度和当前可审批人；轮到你审批时出现「审批通过」「驳回」，提交人本人看不到审批按钮，只能终止工单。

## 权限

| 权限码 | 说明 |
|---|---|
| `export.view` / `export.view_batch` | 查看单实例 / 批量导出工单 |
| `export.submit` / `export.submit_batch` | 提交导出 / 批量导出 |
| `export.download` | 下载导出文件（高危） |
