# 登录、两步验证与账号安全

## 登录页

登录页的卡片里只有账号、密码、“记住账号”和登录按钮。管理员启用了 LDAP 时，卡片顶部多一个“LDAP 统一认证”页签（用公司目录账号登录）；启用了单点登录时，卡片底部“其他登录方式”下是对应的登录按钮（飞书、钉钉、企业微信、公司 SSO 等）。左侧是平台的品牌介绍，右上角可切换明亮 / 深空 / 护眼主题。

- **选对页签**：账号用错了登录方式（例如 LDAP 账号在“账号密码”页签登录），页面会提示该账号应使用的方式，切换页签或点对应的登录按钮即可；
- **记住账号**：只把账号记在本机浏览器里，不保存密码；取消勾选后下次登录不再预填；
- **显示 / 隐藏密码**：密码框右侧的眼睛按钮；
- **忘记密码**：点“忘记密码？”按账号类型查看找回方式，见下面“忘记密码”；
- **登录安全**：连续输错密码会临时锁定账号（见“账号锁定”）；登录、登录失败、账号锁定等所有操作都记录审计。

### 忘记密码

| 账号类型 | 怎么办 |
|---|---|
| LDAP / AD 域账号 | 到公司统一身份平台找回密码；平台不保存也无法重置域密码 |
| 本地账号 | 联系管理员在“系统管理 › 用户管理”里重置密码；管理员可以“系统生成临时密码”，你首次登录后须先修改密码 |
| 钉钉 / 飞书 / 企业微信等单点登录账号 | 无需平台密码，点登录页上对应的登录按钮即可 |

连续输错密码被临时锁定时，等锁定时间到后再试，或联系管理员解锁。

## 登录方式

登录页按管理员配置显示以下入口，可以并存：

| 方式 | 说明 |
|---|---|
| 本地账号密码 | 平台自己的账号。 |
| LDAP | 在同一个账号密码表单里输入公司目录账号；平台不保存 LDAP 密码，忘记密码请到公司统一身份平台找回。 |
| 单点登录（SSO） | 页面上的"使用 xxx 登录"按钮：飞书 / Lark、钉钉、企业微信、OIDC（公司 SSO）、CAS、Slack。点击后跳转到对应授权页，授权后回到平台。 |

登录页的"本地账号密码表单"可被管理员设为始终显示 / 折叠 / 隐藏。**超级用户永远可以用 `/login?local=1` 走本地账号**——即使 SSO 故障或表单被隐藏，管理员也不会被锁在门外；超级用户默认只允许本地登录（不走 LDAP / SSO）。

> 原型体验：登录页底部的"原型演示账号"下拉框可一键填入账号；密码 `Dba@2026`。点击飞书 / 钉钉 / 企业微信 / 公司 SSO 按钮会模拟授权过程，并按邮箱匹配到对应的演示用户（例如钉钉对应 tl_wang，飞书对应 rd_zhou）。

## 外部账号如何对应到平台用户

SSO / LDAP 登录成功后，平台按"匹配依据"（第三方 ID → 用户名 → 邮箱，由可靠到不可靠）寻找已有用户：

- 已绑定过的外部身份直接登录；
- 邮箱匹配只在**恰好匹配一个用户**且 IdP 没有声明"邮箱未验证"时才采用；
- 找不到时按该登录方式的"首次登录策略"：仅限已有用户（拒绝登录）或自动创建用户（随机不可用密码，并按入组规则加入权限组 / 资源组）；
- **已停用的用户一律拒绝**；超级用户按设置可拒绝外部登录。

如果你用 SSO 登录后提示"账号不存在"，说明管理员选择了"仅限已有用户"，请先联系管理员建号。

## 两步验证（2FA）

是否需要两步验证取决于两点：你是否已经绑定，以及管理员是否开启了"强制两步验证"。

- 已绑定：账号密码（含 LDAP）通过后，还要输入 **TOTP 动态口令**（验证器 App，6 位、30 秒一变）或**短信验证码**（6 位，5 分钟有效，同一号码 60 秒内只能发一次）；
- 未绑定但被强制：第一次登录时引导你绑定——用验证器扫描二维码（也可手动输入密钥），输入一次口令确认后才算绑定成功；
- 通过浏览器跳转的 SSO 登录默认视为 IdP 已验证，不再做两步验证（管理员可开启"外部登录后仍要求两步验证"）；
- 同一个口令在同一个时间窗口内不能重复使用；验证码连续输错会作废，登录级别的失败次数超限则需要重新输入密码。

账号密码通过后，登录页切换到“两步验证”步骤：输入 6 位验证码后点“验证”，输错会提示“验证码不正确或已过期”；“← 返回重新登录”回到账号密码步骤，“改用短信验证码”把验证码发到已绑定的手机。头像菜单里的“两步验证”显示当前是否已绑定，未绑定时可以“绑定验证器”：用验证器 App（Google Authenticator / Microsoft Authenticator 等）扫描二维码，输入 6 位动态码即可。

换手机后验证器丢失：联系管理员在[用户管理](#help/sysadmin)里"重置 2FA"，然后重新绑定。

> 原型体验：dba_li、admin 需要两步验证，验证码固定 `123456`；短信方式会提示"已发送，固定 123456"。

## 账号锁定

连续输错密码达到阈值后账号被临时锁定一段时间，期间即使密码正确也无法登录。阈值默认 **5 次**（可设 1–100），锁定时长默认 **300 秒**（5 分钟，可设 10–86400 **秒**），由管理员在"登录与安全设置"里调整，保存后立即生效。

- 为避免泄漏"账号是否存在"，所有失败（用户不存在 / 密码错 / 被停用 / 被锁定）都只提示同一句"用户名或密码错误"；
- 只有真实存在的账号才累计失败次数；锁定时间一过，下一次尝试前失败计数自动清零；
- 也可以请管理员在[用户管理](#help/sysadmin)里"解锁"（把失败计数清零）；
- 阈值与时长见[登录与安全设置](#help/sysadmin)。

> 原型体验：dev_liu 是一个已锁定的演示账号，选它登录也只会看到"用户名或密码错误"，原因要到系统审计和用户管理里看。想体验锁定：用某个账号连续输错密码（超级用户可先把"登录失败几次锁账号"调小、锁定时间调到 10 秒再试），期间输对密码也登录不上，等锁定时间过了才恢复。

## 修改密码与会话

- 只有**本地账号**可以在头像菜单里修改密码；LDAP / SSO 账号的密码在各自系统里维护；
- 新密码要满足管理员设置的密码策略：最小长度（默认 9 位，可设 6–64）、复杂度（默认不要求；开启后须同时含字母、数字和特殊字符），并且不能是常见弱口令、纯数字，也不能与用户名、姓名、邮箱太相似，不能与当前密码相同；弹窗里的提示会随设置变化；
- 登录本身不校验密码策略，策略只在新建 / 改密时生效；
- 登录会话有有效期（由管理员设置，默认 300 分钟，可设 5–43200 分钟；默认关闭浏览器即退出），滑动续期，超过这么久没有任何操作才需要重新登录；每次登录都会换发新的会话，不沿用旧会话。

## 登录方式管理（管理员）

菜单：**系统管理 › 登录方式**（仅超级用户）。自定义用户的登录验证方式：LDAP / AD 域、OIDC、钉钉、CAS、飞书、Lark、Slack、企业微信都可以用来登录，可以同时启用多种，同一类型也可以添加多个（例如两套 LDAP、飞书和 Lark 各一个）；配置保存即生效，不用重启；密钥加密存储，页面不回显，编辑时留空 = 不修改。

> ⚠ **启用前必须测试通过**；连接配置已变更时需重新测试。本地账号密码登录永远保留给超级用户（`/login?local=1`），避免外部登录配错把自己锁在外面。

页面从上到下：

- **概览**：已定义（外部）、启用中、未测试、测试异常四个数字；
- **已定义的登录方式**：第一行是内置的“本地账号密码”，不可停用或删除。其余行显示类型、状态（启用 / 异常 / 停用 · 已测试 / 停用 · 未测试）、登录页上的呈现（LDAP 走账号密码页签，其余是按钮）、首次登录策略、默认入组和最近成功登录；可拖动 ⋮⋮ 或用 ↑ ↓ 调整登录页按钮顺序；操作有“配置”“测试”“启用 / 停用”，停用后才能“删除”（配置与密钥一并清除，该方式下的外部身份绑定也一并清除）；
- **通用规则**：见下表；
- **登录页预览**：按当前设置画出登录页，只列出“启用且测试通过”的方式，停用或异常的不显示；多种方式同时启用时按列表顺序排列。每次打开登录页都会读取这里的配置，退出登录即可看到变化。

启用、停用、删除、保存配置和保存通用规则前都会弹出确认框，所有变更写入系统审计。

### 添加与配置

点“＋ 添加登录方式”选类型、填名称（同时是登录页按钮文字），添加后进入配置，测试通过才能启用。配置弹窗分五块：

| 块 | 说明 |
|---|---|
| 基本信息 | 名称；首次登录策略：自动创建用户，或仅允许已有用户登录（不自动创建）；匹配依据：用户名 / 邮箱 / 手机号 / 第三方 ID（钉钉 UserID / 飞书 OpenID / Slack ID），可多选；“每次登录都按入组规则同步”（只增不减，不会移除手工加入的组） |
| 连接参数 | 见下表。连接相关参数变更后，已启用的方式会被自动停用、测试结果作废，需重新测试；属性映射、入组规则、同步开关的变更不需要重新测试 |
| 用户属性映射 | 外部属性 → 平台的用户名 / 姓名 / 邮箱；多个备选属性之间用竖线分隔，从前往后取第一个有值的；内置派生属性 `email_local`（邮箱 @ 前的部分） |
| 默认入组 | 自动创建的用户未命中任何入组规则时加入的权限组 / 资源组；为空则用“登录与安全设置”里的新用户默认权限组 / 资源组 |
| 入组规则 | 按外部属性自动加入权限组 / 资源组，只增不减；每条规则由外部属性、比较（等于 / 包含）、值、加入的权限组和资源组组成，至少要加入一个组 |

匹配依据决定外部账号怎么找到平台里已有的用户，固定从可靠到不可靠的顺序匹配：第三方 ID → 用户名 → 邮箱；邮箱只在恰好匹配一个用户且 IdP 没有声明“邮箱未验证”时才采用。

各类型的连接参数（带“回填”的是登录成功后把第三方 ID 回填到用户资料，用于通知 @，还需开启“通用规则”里的回填开关）：

| 类型 | 参数 |
|---|---|
| LDAP / AD 域 | 服务器地址；连接方式（LDAPS（SSL）/ StartTLS / 明文，不建议明文）；校验服务端证书；绑定 DN（查询账号）与绑定密码；用户搜索 Base 与搜索过滤（如 `(sAMAccountName=%(user)s)`，`%(user)s` 为登录时输入的账号，先搜后绑，必须恰好搜到 1 个条目），或改用“用户 DN 模板”直接绑定，两种方式二选一；每次登录同步更新姓名 / 邮箱 |
| OIDC | Wellknown URL；Client ID / Client Secret；Scopes；id_token 签名算法（RS256 / ES256，固定为所选值以防算法混淆，`none` / HS256 一律拒绝） |
| 钉钉 | AppKey / AppSecret；企业 CorpId（可空，让授权页直达本企业；只有本企业成员能查到 userid，天然限定企业）；回填钉钉 UserID |
| CAS | CAS 服务地址；协议版本（3 / 2 / 1）；校验 CAS 服务端证书；强制 service URL 使用 https；退出时同时退出 CAS（全局登出） |
| 飞书 | App ID / App Secret；租户限制 tenant_key（可空，填写后只允许该租户的成员登录）；回填飞书 OpenID |
| Lark（国际版飞书） | 同飞书；站点固定为 open.larksuite.com |
| Slack | Client ID / Client Secret；限制工作区 Team ID（可空）；使用 “Sign in with Slack”（OpenID Connect）；回填 Slack ID |
| 企业微信 | 企业 CorpId、应用 AgentId、应用 Secret；授权方式（企业微信内免登 + 浏览器扫码 / 仅浏览器扫码）；可信域名即回调地址 |

除 LDAP 外，OAuth 类的方式都有只读的**回调地址**（`平台对外地址/login/sso/<id>/callback`），需要填到身份提供方的应用配置里。密钥类字段保存后不回显：留空表示不修改，已配置的会显示“已设置（留空不修改）”。保存前会列出变更内容并二次确认；审计里只记“已修改”，不记密钥内容。

### 测试

测试使用已保存的配置，测试结果逐行列出：连接、取得的属性、命中的入组规则，以及与已有用户的匹配结果（匹配到超级用户且设置了“超级用户只能本地登录”时、或设置为“仅限已有用户”却匹配不到时，平台不会放行）。

- **LDAP**：填测试账号和密码（空密码一律拒绝，避免被当作匿名绑定而“成功”；密码只用这一次，不保存、不进日志 / 审计），用该账号走一遍登录校验；
- **其他类型**：走完整的授权 / 令牌 / 签名校验（OIDC 校验 id_token 的签名、nonce、aud、exp，CAS 校验 ticket 与 service）；原型里直接模拟授权，授权用户是该方式预置的演示用户；
- 测试**不创建用户、不写绑定、不建会话**；测试失败时已启用的方式会被自动停用；审计里只记成败，不含密码 / 令牌。

### 通用规则

| 设置项 | 说明 |
|---|---|
| 本地账号表单 | 始终显示、折叠或隐藏（仅 `/login?local=1` 可用，超级用户后门） |
| 超级用户只能本地登录 | 超级用户不参与外部登录；取消后外部身份匹配到超级用户时将允许登录，请确认身份提供方的账号安全 |
| 外部登录后仍要求两步验证 | 默认关：认为身份提供方已验证 |
| 登录后回填第三方 ID | 登录成功后把第三方 ID 回填到用户资料，用于通知 @ 人 |
| 允许用户自行绑定 / 解绑外部账号 | 用户可自行绑定、解绑自己的外部账号 |

保存通用规则前会列出变更差异，确认后立即生效，无需重启。

## 登录与安全设置（管理员）

菜单：**系统管理 › 登录与安全设置**（仅超级用户）。各设置项的取值范围、默认值和风险提示见 [系统管理](#help/sysadmin) 的“登录与安全设置”；外部登录（LDAP / OIDC / 钉钉 / CAS / 飞书 / Slack / 企业微信）在“登录方式”里配置。

页面顶部是账号锁定策略、两步验证（已绑定账号数 / 总数）、密码策略、会话 / JWT 四个概览数字，底部“已定义的登录方式”是只读摘要，可点“去配置登录方式”。工具栏的“预览两步验证页”按当前设置画出两步验证页：验证方式、验证码、获取验证码、验证，强制绑定时还有二维码与密钥。两步验证方式只有 TOTP 与短信，**没有备用码**，丢失设备请联系管理员在“用户管理”里“重置 2FA”。

一次登录依次经过：

1. 输入账号：本地账号密码，或点登录页上的外部登录按钮（SSO）；
2. 锁定检查：连续输错达到阈值就锁定一段时间，提示语不区分原因；
3. 验证身份：本地密码（符合最小长度）或外部认证；超级用户只走本地；
4. 两步验证：强制时未绑定先绑定、已绑定输入动态码；自愿时只有已绑定的用户输入动态码；经浏览器跳转的 SSO 默认不再做两步验证，可在“登录方式 › 通用规则”里改为仍要求；
5. 建立会话：按会话有效期滑动续期，可设为关闭浏览器即退出；登录成功一律换新会话与新 CSRF 令牌（防会话固定）；
6. 进入系统：页面叠加水印（如已开启），所有操作写入审计。

本地账号密码永远可用（`/login?local=1` 是超级用户后门）。

## 通过 API 调用

脚本和第三方系统可以用 JWT（用户名 + 密码换取令牌，有效期默认 4 小时，可设 1–720 小时）调用接口：受锁定与"API 用户白名单"约束（白名单为空表示不限制，非空时只有名单内的用户能用），默认**不走**两步验证；管理员可开启"API 登录要求动态口令"，此时已绑定 TOTP 的用户必须在请求里带 `otp` 字段。
