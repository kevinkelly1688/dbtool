说明（改了什么、窗口变窄时怎么办）
  • 审批流预览不再占一张卡片，SQL 编辑区整体上移约 130px；悬停在审批组上看可审批人员的提示、某一级无人可审标红，都保留。
  • 选项组：三项放在一个和输入框一样高的框里，项与项之间一条细线；顺序和现在页面里的顺序一样（批量提交、执行前备份、跳过语法检查）。勾上“跳过语法检查”时整个框变橙色提醒（它有风险，勾选时的确认弹窗不变）。
  • 批量提交始终显示。可用的条件和现在完全一样（有批量权限、资源组里有可批量的实例、当前选的实例是可批量的类型，默认只有 SQL Server；已经打开批量时一直可用，免得没法关闭）；不可用时置灰、不能勾，鼠标停上去提示原因：不是 SQL Server 提示“仅支持 MSSQL”，是 SQL Server 但没有批量权限提示“没有批量提交的权限”。打开批量后的界面（实例多选列表）不变。
  • 另外两项的出现规则不变：备份在 SQL Server / Redis / 批量上线 / 未配 goInception 时不显示；“跳过语法检查”只有超级用户有，Redis / 批量上线时不显示。
  • 窗口变窄时：审批流换到标题下面一行；3 列宽度时名称框占第 1 列、选项组占后 2 列；2 列及以下名称框一行、选项组在它下面一行；手机宽度选项组里三项上下排。可以拖动窗口宽度看。
  • 只改“提交 SQL 工单”页；“数据导出”的提交页暂时不动（它和这一页共用审批流预览的脚本）。
